# Skills

Projektweite Skills für Claude Code. Jeder Unterordner enthält eine `SKILL.md`,
die Claude automatisch lädt, sobald die Beschreibung zur Aufgabe passt.

## emil-design-eng

Design-Engineering-Wissen von Emil Kowalski (Vercel, Linear; Autor von Sonner
und Vaul): UI-Politur, Komponenten-Design, Animations-Entscheidungen – Dauern,
Easing, Spring-Physik – und die unsichtbaren Details, die eine Oberfläche
stimmig machen. Greift bei Arbeit am Frontend in `apps/web`.

- Quelle: <https://github.com/emilkowalski/skills> (Skill `emil-design-eng`)
- Stand: Upstream-Commit `70744e3` vom 2026-07-27
- Lizenz: MIT, siehe `emil-design-eng/LICENSE`

Aktualisieren: `SKILL.md` aus dem Upstream-Repo neu kopieren und den Commit-Stand
oben nachziehen.

installiert sind: `review-animations`, `improve-animations`,
`find-animation-opportunities`, `animation-vocabulary`, `apple-design`,
